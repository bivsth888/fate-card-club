# Fate Card Club

In Between card game and shared-pot tracker, built for a shared phone, tablet, or computer.

## Play

Choose Live table to track physical cards, or Play on this device for animated dealing and automatic results. No account is needed. Games and preferences are saved in each browser's local storage, not on a server. Saved games do not transfer between website addresses or devices.

## Hosting

This is a static HTML, CSS, and JavaScript site with no build step or dependencies. GitHub Pages serves the root folder of the main branch. The .nojekyll file disables Jekyll processing. Update the files on main to publish changes.

## Local preview

Run `python -m http.server 8000` from this folder, then open http://localhost:8000.
